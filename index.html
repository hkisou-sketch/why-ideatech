なぜ、IDEATECHなのか。 コンテンツが
あふれるほど、
信頼が差になる。

生成AIで、誰でも、いくらでも文章をつくれるようになりました。どこかで見たようなコンテンツが増えるほど、買い手は、何を信じて選べばいいのかを慎重に見極めるようになります。

IDEATECHは、買い手に実際に聞いた一次データを起点に、信頼のコンテンツをつくる会社です。信頼されたコンテンツは、買い手の納得を生み、生成AIにも学ばれ、ブランドとして積み上がっていきます。

// WHY

スロップがあふれる世界で、
信頼こそが鍵になる。

AIで量産された中身の薄いコンテンツは、英語で「スロップ（slop）」と呼ばれ、あちこちで目にするようになりました。同じような情報が並ぶなかで、買い手が最後に頼るのは、信じられるかどうかです。

  • 量では、
    もう差がつかない。

    記事の本数も更新の頻度も、AIを使えば誰でも増やせます。同じような情報が増えるほど、買い手の目にはどの会社も同じに見えてしまいます。

  • 買い手は、
    信じられる情報で選ぶ。

    買い手は営業に会う前に候補を絞り、本命をほぼ決めています。その判断を支えるのは、出どころが分かり、自分で確かめられる情報です。説明が難しく高単価な商材ほど、社内の関係者全員が納得できる根拠が求められます。

  • 信頼は、
    積み上がって差になる。

    一度信じてもらえたコンテンツは、買い手の記憶にも、AIの回答にも残ります。信頼は時間をかけて積み上がるので、ほかの会社がすぐにはまねできません。

信頼のコンテンツが、
差別化になるまで。

信頼できるコンテンツは、買い手とAIの両方に届き、時間をかけてブランドになります。

  1. 信頼のコンテンツ

    買い手に実際に聞いた一次データと、誰に・いつ・どう聞いたかが分かる根拠でつくる。

  2. 顧客に、
    納得感が生まれる

    売り込まれる前に、自分で確かめて納得できる。社内を説得する材料にも、そのまま使える。

    生成AIに、
    学ばれる

    出どころの確かな情報は、AIが回答の根拠として参照し、学んでいく。

  3. ブランドが、
    積み上がる

    買い手の記憶にも、AIの回答にも、「この分野ならこの会社」という印象が残っていく。

  4. 差別化になる

    機能や価格で並べられても、選ばれる理由を持てる。量産されたコンテンツには、まねできない差になる。

AIに推奨されることや、業界の比べ方の基準をつくる側に回ることは、この積み重ねの先にあります。

施策は、コンテンツを運ぶ車両にすぎない。

マーケティングは、施策から考えはじめられがちです。展示会に出るか、ウェビナーを増やすか、広告を回すか。けれど施策は、コンテンツを買い手のもとへ運ぶ車両にすぎません。

積んでいるコンテンツが買い手に響かなければ、施策を増やしても商談にはつながりません。私たちは、施策を決める前に「誰に、何を語るか」を決め、それを形にするコンテンツから考えます。

  1. 起点

    誰に、何を

    顧客は誰か。その人に何を約束するか（STP・価値提案）。

  2. 私たちがつくるもの

    コンテンツ

    価値提案を、買い手が受け取れる形にしたもの。調査データ、白書、比べ方のガイド、商談資料。

  3. 車両

    施策

    • 展示会
    • セミナー
    • ウェビナー
    • プレスリリース
    • 広告
    • 営業
  4. 届け先

    買い手の頭の中

    1. 気づく
    2. 調べる
    3. 比べる
    4. 決める

展示会は、候補を絞った買い手とじっくり話せる大切な場です。ただ、そこで何を渡し、どの商談につながったかを示せないと、予算は削られやすくなります。何を持っていくかを先に決め、その効果を追えるようにしておくと、展示会の価値を社内で説明しやすくなります。

なぜ、「マーケティング・アセット」と呼ぶのか。

つくったあとも使われ続け、信頼が積み上がっていくからです。

買い手が課題に気づくとき、候補を比べるとき、社内を説得するとき。どの段階でも、判断の材料になるのはコンテンツです。独自調査のデータは実施した会社にしか残らず、白書、営業資料、プレスリリースなど12種類以上の形に展開して、何年も使い続けられます。だから私たちは、コンテンツを「資産」と呼んでいます。

生成AIが、BtoBの買い手の調べ方と比べ方を変えたからです。そのAIが回答の根拠にするのも、出どころの確かな情報です。

// HOW

信頼されるコンテンツを、
こうしてつくる。

どのコンテンツでも、次の4つを守っています。

実際に聞いたデータから始める。

5年で800社以上・2,500件以上の一次調査を手がけてきました。条件を絞った100名以上の調査もできるので、ニッチなBtoB領域でも一次データをつくれます。

誰に、いつ、どう聞いたかを示す。

調査の対象、期間、方法、回答数を明記します。回答データも、意味の通らない回答を除いてから使います。出どころの分かる数字は、買い手が自分で確かめられ、メディアやAIにも引用されやすくなります。

第三者に語ってもらう。

調査リリースがメディアに取り上げられると、自社の外からも語られるようになります。第三者の言葉で語られた情報は、買い手にとっても確かめやすい根拠になります。

売り込まずに、選ぶ材料を渡す。

自社を1位に並べるだけの比較記事はつくりません。調査データをもとに、買い手が選ぶときに確かめるべき点を整理します。

マーケティングチームが経営から問われるのは、マーケ起点のパイプライン金額、コンペ勝率、商談1件あたりの獲得コストの3つです。私たちは、この3つの数字を動かすことを目標に、誰に何を語るコンテンツをつくるかを決めます。

  • マーケ起点の
    パイプライン金額

    買い手が営業に会う前に候補を絞り、自社はその段階で外れている。

    動かすもの
    課題に気づく段階から比べる段階までに、買い手に届くコンテンツ。調査データ、白書、比べ方のガイド
    測り方
    コンテンツ経由の商談と指名での問い合わせ、メディアやAIでの取り上げられ方

  • コンペ勝率対上位企業・対外資

    上位企業や外資と比べられても、勝ち筋を根拠で示せない。

    動かすもの
    上位企業や外資と並べられたときに、自社の強みが伝わる調査データと、商談や稟議で渡す根拠資料
    測り方
    コンペの勝敗とその理由、商談での資料の使われ方

  • 商談1件あたりの
    獲得コスト

    展示会やブランドの貢献を数字で説明できず、予算を削られる。

    動かすもの
    展示会やセミナーで渡すコンテンツ。1つの調査を12種類以上のアセットに展開し、同じ予算で使い回す
    測り方
    施策ごとの費用と、そこから生まれた商談の数

導入後の活用が、次の「課題認識」の起点になる。購買は∞のループで続いていく。

展示会が力を発揮するのは、STAGE 4「ベンダー商談・最終選定」です。絞り込んだ相手とじっくり話したい買い手に、確かめるための材料を渡せる場になります。その前のSTAGE 1〜3で候補に入っていることが前提です。

だから、この順番で進めます。

誰に何を語るかを決め、つくり、届け、測る。この4つを一気通貫で担います。

  1. 誰に、どの段階で語るかを決める。

    自社の顧客は誰か。どの部門・役職の買い手が、どの段階で、何に迷っているのか。全社のカテゴリと事業部ごとの商材の両方で、IDEAインサイトが語るべきことを特定し、GTMやABMの設計図にします。

    • IDEAインサイト

  2. 信じてもらえる材料をつくる。

    独自調査を起点に、調査リリース、白書、比べ方のガイド、商談資料まで、段階ごとに必要なコンテンツをつくります。1つの調査を12種類以上のアセットに展開できます。

    • リサピー®
    • レポピー®
    • ハクピー®

  3. 届けて、第三者に語ってもらう。

    プレスリリース、PR企画、業界メディアへの露出で、自社の外からも語られる状態をつくります。第三者の言及が増えるほど、買い手にもAIにも見つけてもらいやすくなります。

    • 調査PR

  4. 測って、次の一手を決める。

    コンテンツ経由の商談、第三者の言及、AIでの取り上げられ方を、毎月同じ物差しで測ります。3つの数字につながる形で成果を示し、経営への説明と予算の判断に使えます。

    • IDEA LLMO BOARD

そのために、提供しているもの。

どのサービスも、買い手に信じてもらえるコンテンツをつくり、届け、測るためのものです。単体でも、組み合わせても使えます。

  • リサーチマーケティング リサピー® 独自調査を起点に、メディアに取り上げられる調査リリースをつくります。 詳しくみる
  • レポートマーケティング レポピー® 調査レポートで、比較と稟議に使える根拠を残します。 詳しくみる
  • ソートリーダーシップマーケティング ハクピー® 業界カテゴリーを定義する基本書をつくり、業界の中での立ち位置を固めます。 詳しくみる
  • LLMOコンテンツ コラピー® 調査で見えた買い手の課題を、製品の理解へつなぐ記事をつくります。 詳しくみる
  • コンテンツ起点の受注・LTV向上 コンテンツセールス® 商談と導入後の場で、コンテンツを営業の武器にします。 詳しくみる
  • LLMO戦略 IDEA LLMO 積み上げたコンテンツが、対話型AIに正しく取り上げられるよう設計します。 詳しくみる
  • LLMOの計器盤 IDEA LLMO BOARD 推奨状況・サイテーション・競合を毎月測り、次の一手を決めます。 詳しくみる
  • 変化し続けるWEBサイト IDEA DESIGN® 強みをAIに正しく理解してもらう、週次で更新し続けるWebサイトです。 詳しくみる

こんなマーケティングチームと、ご一緒したいと考えています。

コンテンツの本数を増やしたいチームより、信頼を積み上げ、その成果を経営に説明したいチームのお役に立てると考えています。

  • 説明が難しく、高単価なBtoB商材を扱っている（ITベンダー・SIerを中心に）
  • 全社マーケティング、または事業部のマーケティングを担っている
  • 競合が多く、上位企業や外資と比べられる
  • 広告とは相性が悪く、商談の起点は展示会・イベント・アライアンスが中心
  • コンテンツはつくっているが、受注への効き目を数字で示せていない
  • GTMやABMのように、「誰に何を語るか」から設計し直したい

よくあるご質問

なぜIDEATECHなのですか？

コンテンツがあふれるいま、買い手が信じて選べるかどうかで結果が変わるからです。IDEATECHは5年で800社以上・2,500件以上の一次調査を手がけ、実際に聞いたデータを起点に、調査リリース、白書、商談資料までを一貫してつくります。信頼されたコンテンツは、買い手の納得を生み、生成AIにも学ばれ、ブランドとして積み上がっていきます。

生成AIでつくる記事と、何が違うのですか？

出どころです。IDEATECHのコンテンツは、買い手に実際に聞いた一次データを起点にし、調査の対象・期間・方法を明記します。誰が、何を根拠に書いたかが分かるコンテンツは、買い手にもAIにも信頼されやすくなります。

なぜ「マーケティング・アセット」という言葉を使うのですか？

つくったあとも使われ続け、価値が積み上がっていくからです。一次データは実施した会社にしか残らず、白書、営業資料、プレスリリースなど12種類以上の形に展開して、何年も使えます。

なぜAIなのですか？

生成AIによって、買い手の調べ方と比べ方が変わったからです。当社の調査では、製品・サービスの選定で生成AIを利用した人は90.6%でした。買い手が変われば、必要なコンテンツも変わります。

成果は、経営に説明できる数字で測れますか？

取り組みのはじめに、マーケ起点のパイプライン金額、コンペ勝率、商談1件あたりの獲得コストにつながる指標を一緒に決めます。コンテンツ経由の商談や第三者の言及、AIでの取り上げられ方はIDEA LLMO BOARDで毎月同じ物差しで測り、どの施策が効いたかを説明できる形でお渡しします。

全社のマーケティングと事業部のマーケティング、どちらと取り組むのですか？

どちらとも取り組みます。全社マーケティングとはカテゴリ全体の調査や白書を、事業部のマーケティングとは商材ごとの比べ方のガイドや商談で渡す資料を、1つの調査データを起点につくります。

「おすすめ◯選」のような比較記事はつくりますか？

自社を1位に並べるだけの比較記事はつくりません。根拠のない順位付けは、買い手にもAIにも見抜かれやすいためです。調査データをもとに、選ぶときに確かめるべき点を整理したガイドをつくります。

展示会やセミナーは、やめたほうがよいのですか？

やめる必要はありません。展示会もセミナーも、コンテンツを買い手に届ける大切な場です。何を持っていき、何を渡すかを先に決めておくと、効果を社内で説明しやすくなります。候補を絞った買い手とじっくり話せる場として、対面の価値は高まっています。

そのコンテンツは、買い手に信じてもらえているか。

いま届いているコンテンツと、足りていないコンテンツを、買い手の目線で整理するところから始めましょう。
